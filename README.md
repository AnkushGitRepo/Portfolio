# Ankush Gupta - Full Stack Developer Portfolio

This is the personal portfolio website of **Ankush Gupta**, a Full Stack Developer and Computer Science student. The portfolio showcases my projects, skills, certifications, and provides a way to contact me. It is built using the **MERN Stack** (MongoDB, Express, React, Node.js) and designed with **Tailwind CSS**.

## 🚀 Features

-   **Hero Section**: Stunning introduction with a light/dark aesthetic.
-   **Projects Showcase**: Highlighted projects with images and descriptions.
-   **Skills Display**: Categorized technical skills (Frontend, Backend, Database/Tools, Soft Skills).
-   **Certifications**: List of professional certifications with direct verification links.
-   **About Me**: Personal biography and professional focus.
-   **Contact Section**: Direct contact information and quick action buttons (Email, LinkedIn, GitHub, etc.).
-   **Responsive Design**: Fully optimized for desktop and mobile devices.
-   **Animations**: Smooth transitions using **Framer Motion**.

## 🛠️ Tech Stack

-   **Frontend**: React (Vite), Tailwind CSS, Framer Motion
-   **Backend**: Node.js, Express.js
-   **Database**: MongoDB (Integrated for potential dynamic features)
-   **Deployment**: Vercel (Frontend), Render/Heroku (Backend - *if applicable*)

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### Prerequisites

-   Node.js (v14+ recommended)
-   MongoDB (Local or Atlas URI)

### 1. Clone the Repository

```bash
git clone https://github.com/AnkushGitRepo/Portfolio.git
cd Portfolio
```

### 2. server Setup

Navigate to the server directory and install dependencies:

```bash
cd server
npm install
```

Create a `.env` file in the `server` directory and add your variables:

```env
PORT=5000
MONGODB_URI=your_mongodb_connection_string
```

Start the server:

```bash
npm run server
```

### 3. Client Setup

Open a new terminal, navigate to the client directory, and install dependencies:

```bash
cd client
npm install
```

Start the React development server:

```bash
npm run dev
```

The application will be available at `http://localhost:5173`.
